# Jogo de Trivia

Este projeto é um jogo de trivia simples desenvolvido com HTML, CSS e JavaScript. O objetivo do jogo é testar seus conhecimentos em diversas categorias de perguntas.

https://alancostaoliveira.github.io/javascript_jogo_trivia/

## Estrutura do Projeto

O projeto contém os seguintes arquivos e diretórios:

- `src/css/style.css`: Estilos CSS para a interface do usuário.
- `src/js/app.js`: Ponto de entrada do aplicativo, gerencia o fluxo do jogo.
- `src/js/questions.js`: Exporta um array de objetos com as perguntas do trivia.
- `src/js/ui.js`: Manipula a interface do usuário e eventos.
- `index.html`: Página principal do jogo.
- `package.json`: Configuração do npm para o projeto.
- `.gitignore`: Lista de arquivos e pastas a serem ignorados pelo Git.
- `README.md`: Documentação do projeto.

## Instalação

1. Clone o repositório:
   ```
   git clone <URL_DO_REPOSITORIO>
   ```
2. Navegue até o diretório do projeto:
   ```
   cd jogo-trivia
   ```

## Uso

1. Abra o arquivo `index.html` em um navegador para jogar.
2. Siga as instruções na tela para responder às perguntas.

## Publicação no GitHub

Para publicar o projeto no GitHub, siga estas etapas:

1. Crie um repositório no GitHub.
2. No terminal, navegue até a pasta do projeto.
3. Execute `git init` para inicializar um repositório Git.
4. Adicione os arquivos com `git add .`.
5. Faça um commit com `git commit -m "Initial commit"`.
6. Conecte o repositório remoto com `git remote add origin <URL_DO_REPOSITORIO>`.
7. Envie os arquivos para o GitHub com `git push -u origin main`.

Certifique-se de substituir `<URL_DO_REPOSITORIO>` pela URL do seu repositório no GitHub.
